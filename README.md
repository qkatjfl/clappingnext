# 👏 Clappingnext (Kotlin-based)
> 스마트폰에 손을 대지 않고, '박수' 소리만으로 음악을 제어하는 접근성 보조 앱입니다.

## 🚀 프로젝트 개요
* **개발 언어**: Kotlin (Android)
* **핵심 기능**: 
    * 실시간 주변 소음 분석 및 박수 소리 감지
    * 타 앱(Spotify, YouTube Music 등) 미디어 컨트롤 (재생/일시정지/다음 곡)
    * 백그라운드 상시 대기 모드

## 🚧 현재 진행

과거에 생각나던걸 AI의 도움을 받아 단순하게 화면, 기본 로직정도만 생각해두고 기본의 기본만 만들어 둔 상태입니다. 코틀린이란 언어도 하면서
처음 알게 되었고, 진행에 있어 AI의 도움이 큰 부분을 차지하여 프로젝트 중에 스스로도 이해하지 못한 부분도 많은것이 사실입니다.
그래도 생각만 하던걸 AI를 통해 스스로 구현해본것에 대해 큰 의미가 있다 생각합니다.


### [미완성 기능: 박수 박자 커스텀]
현재 **"박수 박자 패턴 인식(예: 세 번 치면 이전 곡)"** 기능은 프로토타입 단계입니다. 
* **도전 과제**: 단순히 소리가 큰 것뿐만 아니라, 박수 사이의 간격(Interval)을 타임스탬프로 기록하여 패턴화하는 로직을 설계 중입니다.
* **향후 계획**: 사용자별로 박수 치는 속도가 다르므로, '학습 모드'를 통해 개인화된 박자 패턴을 저장하는 기능을 추가할 예정입니다.

## 💡 개발 중 마주한 기술적 고민
1. 여러 음악앱에 접근하여 컨트롤을 하려다 보니 권한에 대한 문제가 많이 생겨서 아직 해결중에 있습니다.
2. 박수 소리를 듣고 그게 박수 소리인지 아닌지 구분할 수 있게 하는 시스템도 해결중입니다.
3. 사용자의 커스텀 박수 소리를 인식하는 과정에서 그걸 하나의 전체 파동으로 인식할지, 아니면 앱에서 메트로늄을 쳐주고 그거에 따라 사용자가 인식시키고
그거에 따라 각각 분리시켜 인식시킬지 고민중입니다.
